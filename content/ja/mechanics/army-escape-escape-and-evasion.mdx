敵対地域や非許容環境で活動する際、標準的な**陸軍の脱出・回避行動（Army Escape escape and evasion）**プロトコルを熟知しているかどうかが、捕虜となるか生還できるかの分かれ目となります。歴史的なサバイバルドクトリンを分析する場合でも、過酷な大自然のシナリオに野戦技術（フィールドクラフト）を応用する場合でも、**陸軍の脱出・回避行動**戦略の中核原則は、規律、綿密な計画、そして極限状態における冷静な実行力にかかっています。軍事要員が孤立状態にどのように対処するかを理解することで、実証済みの作戦戦術を取り入れ、高リスク環境を安全に切り抜けることができます。

サバイバル状況では、パニックではなく構造化されたアプローチが求められます。何十年にもわたる実戦と現場での適応を経て、軍隊は孤立要員を保護するために生存・回避・抵抗・脱出（SERE）ドクトリンを標準化しました。本ガイドでは、戦術的回避の基本メカニズム、標準化された5つのフェーズ、潜伏場所（ハイドサイト）の選定、ナビゲーション規律、そして救出・回収（エクストラクション）の連携について詳しく解説します。

## ミリタリー回避メカニズムの中核原則

回避行動の本質は、敵対地域や紛争地域を友軍ラインや指定された回収ゾーンへ向かって移動する間、捕獲を免れるための積極的な取り組みです。これには、完全な状況認識、規律ある移動、光線管理（ライトディシプリン）、音響管制（ノイズディシプリン）が不可欠です。

サバイバル野外マニュアルには、孤立した個人が敵に探知されないようにするための具体的な回避メカニズムが概説されています。やみくもに急ぐのではなく、要員は厳格なチェック＆バランスに従います。

| 回避原則 | 作戦上の目的 | 主な現場での課題 |
| :--- | :--- | :--- |
| **音響規律（Noise Discipline）** | 捜索部隊に察知される聴覚的合図を排除 | 乾いた茂み、装具の擦れ・金属音、激しい息遣い |
| **光・偽装（Light & Camouflage）** | シルエットを崩し、反射を排除 | 暗視装置、月明かり、汗の照り返し |
| **痕跡消去（Sign Sanitization）** | 移動ルート上に法医学的証拠・痕跡を一切残さない | 折れた枝、泥上の足跡、遺棄されたゴミ |
| **臭気管理（Scent Management）** | 軍用犬やパトロールによる追跡を防止 | 調理、煙、化学防虫剤、衛生用品 |
| **地形の活用（Terrain Exploitation）** | 微地形を利用して視線を遮断 | 難所となるチョークポイントの通過、岩場の傾斜地 |

回避の安全性を維持するため、オペレーターはスピードと視認性のバランスを取らなければなりません。素早く移動すると騒音や目立つ足跡が生じやすく、移動が遅すぎると脱水症や飢餓、あるいは敵による包囲捜索のリスクが高まります。

## 陸軍の脱出・回避行動における5つのフェーズ

軍事ドクトリンでは、すべての回避シナリオを連続する5つの明確なフェーズに分類しています。**陸軍の脱出・回避行動**フレームワークをマスターするには、各フェーズを独立した作戦上のマイルストーンとして扱う必要があります。

```
[ フェーズ 1: 即時行動 ] ──> [ フェーズ 2: 初動移動 ] ──> [ フェーズ 3: 潜伏場所 / ハイドサイト ]
                                                                                   │
[ フェーズ 5: 回収 / 救出 ] <── [ フェーズ 4: 回避移動 ] <─────────────────────────┘
```

### フェーズ 1: 即時行動（Immediate Actions）
孤立した直後の最初の数分間が最も重要です。要員は周囲の環境を素早く評価し、重度の外傷を処置し、環境脅威や化学的脅威から身を守り、必須装備を回収し、孤立地点の痕跡を消去（サニタイズ）した上で、直ちに敵の視界外へ移動するよう指示されます。

### フェーズ 2: 初動移動（Initial Movement）
危機の発生現場から離れたら、回避者は欺瞞的な移動経路を用いて敵との接触を断ちます。上り坂へ移動したり、自然の谷筋（ドロー）を利用したりすることで、敵からの観測を遮ります。初動の追跡を撒くため、通常は不規則なジグザグパターンで移動しながら、回避行動計画（EPA: Evasion Plan of Action）の実行へと移行します。

### フェーズ 3: 潜伏場所（Hole-Up / Hide Site）
回避者は、地上および上空の捜索者から360度身を隠せる安全な場所で停止します。ここでは、長期的な怪我の処置、通信の試行、装備の棚卸しを行い、今後の長距離移動に向けた計画を最終決定します。

### フェーズ 4: 回避移動（Evasion Movement）
このフェーズは、指定された潜伏場所と集結点（ラリーポイント）の間を慎重かつ隠密に移動する段階です。視界条件が自らに有利な場合にのみ移動し、「停止・観察・聴取・嗅ぎ分け（SLLS: Stop, Look, Listen, and Smell）」メソッドを用いて継続的に警戒を行います。

### フェーズ 5: 回収（Recovery）
最終フェーズは、正規部隊または非正規部隊の回収チームとの合流です。回避者は事前設定されたコードを使用して身元を認証し、正確な位置を知らせ、合流時には指示に従う非脅威的な姿勢をとります。

| フェーズ | 主な目的 | 主要なアクション項目 | よくあるミス |
| :--- | :--- | :--- | :--- |
| **1. 即時行動** | 初期の接触を断つ | 簡易迷彩の適用、必須装備の回収、現場の痕跡消去 | 状況を評価せずに慌てて走り出す |
| **2. 初動移動** | 脅威との距離を確保 | 高地/不整地の移動、ジグザグ進路の実行 | 明白な足跡や直線的な経路を残す |
| **3. 潜伏場所** | 体力回復と計画立案 | 水分補給、EPAの確認、無線通信の確立 | 第二の脱出ルートがない場所を選ぶ |
| **4. 回避移動** | 安全な移動の実施 | ポイント・ツー・ポイント移動、光・音響規律の徹底 | 視界の良い日中ピーク時の移動 |
| **5. 回収** | 安全な合流・救出 | 認証コードの送信、回収チームの指示遵守 | 救出部隊に向かって攻撃的に接近する |

## 野外ナビゲーションと移動戦術

敵対地域での移動は、一般的なハイキングやオリエンテーリングとは根本的に異なります。回避シナリオにおいて、道路、トレイル、尾根線、開けた土地は極めて危険なエリアとなります。ナビゲーションには、推測航法（デッドレコニング）、地形照合法、そして静粛な歩行技術が求められます。

### 回避移動テクニック
不慣れな地形を通過する際、戦術マニュアルではいくつかの重要な移動規律が強調されています。

* **ポイント・ツー・ポイント・ナビゲーション：** 遠くの漠然とした地平線に向かって歩いてはなりません。中間にある遮蔽物（密集した藪、巨岩、くぼ地など）を選び、そこへ静かに移動して停止し、周囲を観察してから次の目標ポイントを選びます。
* **シルエットの回避：** 軍事的な稜線（ミリタリークレスト）や尾根の頂上を避けます。丘の頂上を歩くと、空を背景に自分のシルエットが浮き彫りになってしまいます。尾根の少し下にある自然の等高線に沿って移動します。
* **線状危険地帯（LDA: Linear Danger Areas）：** 道路、小道、河川、送電線などは極めて危険なエリアとして扱います。数分間エリアをじっくり観察した後、低地、カーブ、または植物の密集したセクションを選んで横断します。
* **足跡・痕跡の遮断：** 可能な限り、岩、木の根、固く締まった砂利などの硬い表面を踏んで歩きます。泥の縁、柔らかい土、踏むと目立つように折れる脆い植物は避けてください。

| 地形タイプ | 戦術的利点 | 固有のリスク | 推奨テクニック |
| :--- | :--- | :--- | :--- |
| **密林・森林地帯** | 頭上および地上からの優れた隠蔽性 | 乾いた小枝や落ち葉による大きな騒音 | 低姿勢の屈み歩き。かかとからつま先への慎重な足運び |
| **岩がちの山腹** | 足跡の痕跡がほとんど残らない | 滑落リスク。転石による反響音 | 山頂を避け、等高線に沿って慎重に移動 |
| **湿地・沼沢地** | 車両パトロールの進入を阻止 | 移動速度の低下、激しい体力消耗、水系感染症の危険 | 高くなった土手状の草地を進む。上陸地点の痕跡を消去 |
| **開けた農地** | 漆黒の闇の中での迅速な移動が可能 | 熱画像光学機器や航空追跡に対して極めて脆弱 | 基本的に回避。どうしても通る場合は林縁や排水溝に沿う |

さらなる野戦技術やサバイバル方法論については、[アメリカ陸軍（United States Army）](https://www.army.mil/)の公式トレーニングリソースを参照し、基本的な運用基準を確認してください。

## 潜伏場所（ハイドサイト）の選定と管理

潜伏場所（ハイドサイトまたはホールアップサイト）は、快適なキャンプ地ではありません。探知を逃れながら一時的に身を隠すための、極めて隠蔽性の高い陣地です。適切なサイトを構築するには、敵の接近経路の可能性を分析し、即座に退避できる脱出経路を確保する必要があります。

```
       [ 脱出ルート B ]
               ▲
               │
[ 観測所 1 ] ◄── [ 潜伏場所 / ハイドサイト ] ──► [ 観測所 2 ]
               │
               ▼
       [ 脱出ルート A ]
```

潜伏場所を評価する際は、以下の条件を満たしているか確認します。

1. **多角的な隠蔽性：** 地上からの捜索と、上空からの観測（ドローン、航空機）の双方から遮蔽されていること。
2. **観測・聴取ポスト（OP/LP）：** 自らの位置を晒すことなく、接近する捜索者を早期に発見できる明確な視界があること。
3. **複数の脱出経路：** 危険エリアに向かうことなく退避できる、遮られていない明確な出口ルートが少なくとも2つあること。
4. **環境からの保護：** 体温低下や熱中症、肉体的な消耗を防ぐため、極度の寒さ、風、直射日光から遮断されていること。
5. **信号発信能力：** 回収部隊に対して見通し線（ライン・オブ・サイト）での無線通信や、隠密な視覚シグナルを送れる配置であること。

| ハイドサイトの特徴 | 望ましい特性 | 不適切な条件 |
| :--- | :--- | :--- |
| **位置** | 起伏のある地形の中腹 | 尾根の頂上、谷底、自然な通路のボトルネック |
| **遮蔽と隠蔽** | 鬱蒼とした生きた植物、自然の岩の窪み | 崩れやすい枯れ木の構造物、不自然に見える人工物 |
| **水源との距離** | 200〜400ヤード離れている（死角を利用してアクセス可能） | 水源のすぐ隣（敵のパトロール頻度が高い） |
| **脱出路** | 濃密な藪へと続く分散された脱出ルート | 行き止まりの渓谷、崖下、フェンスで囲まれたエリア |

## 通信、シグナリング、および回収（救出）作戦

回収を成功裏に完了させることは、あらゆる**陸軍の脱出・回避行動**ミッションの最終目標です。孤立した個人が自らの身元を正しく認証し、救出部隊へ安全に合図を送れなければ、サバイバルギアを持っていても意味がありません。

### 認証と合流時のセキュリティ
現代の捜索救助（SAR）または戦闘捜索救助（CSAR）環境では、回収部隊はすべての信号を慎重に扱います。捜索チームは、回避者が敵に脅迫されて行動していないか、罠でないかを検証しなければなりません。

* **認証コード：** 孤立要員は、事前ブリーフィングで決められた4桁の文字、数字、またはチャレンジ・パスフレーズの組み合わせを使用します。
* **ミラーおよびフラッシュシグナル：** 視覚信号は回収機に向けて正確に照射し、地上の敵に察知されるような無差別な光の拡散は避けます。
* **パッシブマーカー：** 地上マーキング（自然物を使って標準化された形状を作るなど）は、回収が間近に迫った場合にのみ展開します。

| 回収方法 | 主な装備 | 基本運用ルール | 安全上の最優先事項 |
| :--- | :--- | :--- | :--- |
| **無線合流** | マルチバンド・サバイバル・トランシーバー | 通信計画に従い、厳格にバースト送信を行う | 方向探知機による逆探知を防ぐため送信時間を最小化 |
| **視覚ビーコン** | IRフィルター付きストロボ、シグナルミラー | 友軍機の飛行方向に向けてのみ発光 | 地上方向への光の漏れを遮断 |
| **火工品フレア** | ペンフレア、昼夜兼用フレア | 回収機からの直接指示があった場合のみ使用 | 上空のローターウォッシュ（吹き下ろし風）や火災に注意 |
| **対空パネル** | 高視認性/熱赤外線リバーシブルパネル | 回収直前に開けた場所に平らに敷く | ローターウォッシュで吹き飛ばされないよう四隅を固定 |

実際の回収時には、回避者は指示に厳格に従わなければなりません。両手を常に見える位置に保ち、すべての武器を安全な状態にして納め、非脅威的な姿勢を取り、回転中のヘリコプターのローターブレードやプロペラに不用意に走り寄らないようにします。

## 回避行動計画（EPA）の策定

高リスク地域や遠隔地の荒野に立ち入る前に、オペレーターは回避行動計画（EPA: Evasion Plan of Action）を策定します。この文書には、通信スケジュール、予定ルート、指定回収ゾーン、重要なサバイバル備蓄（キャッシュ）の位置などが詳細に記載されます。

| EPAの構成要素 | 含まれる重要情報 | 準備のヒント |
| :--- | :--- | :--- |
| **移動コリドー（経路）** | 主要ルートおよび代替ルート、緊急退避方位 | 紙の地図だけに頼らず、主要なランドマークを暗記する |
| **選定潜伏場所** | 主要および予備の潜伏場所のグリッド座標 | 夜間でも識別しやすい地形特徴を選択する |
| **通信・信号計画** | 主要周波数、合言葉、脅迫下コード | 認証キーはシンプルに保ち、完全に暗記する |
| **キャッシュポイント** | 事前配置された水、医療品、食料の場所 | 自然の防水容器を使用し、明確な方位を設定する |

**陸軍の脱出・回避行動**戦略の中核戦術を身につけることで、アウトドアの専門家、危機管理担当者、現場のオペレーターは、極限のサバイバル状況を切り抜けるために必要な精神的レジリエンスと戦術的規律を養うことができます。

## よくある質問（FAQ）

### 陸軍の脱出・回避行動（Army Escape escape and evasion）は何を対象としていますか？
**陸軍の脱出・回避行動**ドクトリンは、孤立した軍事要員が危険な地域を移動し、敵の探知を逃れ、現地で生き延び、友軍の回収部隊との救出連携を成功させるための技術とプロトコルを網羅しています。

### 回避シナリオにおいて最も重要なステップは何ですか？
最も重要なステップは、フェーズ1（即時行動）で発生します。冷静さを保ち、緊急の医療・環境脅威を評価し、現場の痕跡を消去し、敵の視界から即座に逃れることが、敵による迅速な包囲網の形成を防ぐ鍵となります。

### 回避行動における「隠蔽（Concealment）」と「遮蔽（Cover）」の違いは何ですか？
隠蔽（Concealment）は、背の高い草、茂み、影などによって敵の視覚的観測から身を隠すものですが、銃弾や物理的な攻撃を防ぐことはできません。遮蔽（Cover）は、厚い石壁、盛り土、巨大な岩などによって敵の射撃や物理的脅威から身を守るものです。効果的な潜伏場所には、この両方が備わっています。

### サバイバル要員はどのようにして足跡を残さないようにしますか？
要員は、湿った土、泥、折れやすい下草を避け、硬い地面、岩場、木の根の上を歩くことで足跡の規律を維持します。枝を不用意に揺らさず、かかとからつま先へ体重を移動する静粛歩行を行い、移動経路上の痕跡をこまめに消去します。
