## ミッション概要と基本メカニクス

各エリアの詳細に入る前に、ミリタリー脱出ゲームの基本ルールを理解しておくことが生存への鍵となります。多くのレベルでは、クラシックなポイント＆クリックのインベントリ操作と、タイミングが重要なステルス要素が組み合わされています。

インベントリを効率的に管理するため、複数回使用できるツールと、1度しか使えないクエストアイテムを区別して把握しましょう。使い捨ての鍵はドアを開けるとインベントリから消えますが、ワイヤーカッター、ドライバー、懐中電灯などのアイテムは複数のエリアにわたって手元に残り続けます。

### 基本ゲームメカニクス

| メカニクス | 説明 | プレイヤーへのヒント |
| :--- | :--- | :--- |
| **アイテムの合成** | インベントリ画面で2つの異なるオブジェクトを組み合わせてツールを作成する。 | アイテムは常に細部まで観察しましょう。継ぎ目、隠されたバッテリー、ネジ込み式のフタなどに注目してください。 |
| **音声の手がかり** | 歩哨の足音、無線のノイズ、セキュリティアラームの警告音。 | ヘッドフォンを使用し、壁越しの警備兵の巡回距離を正確に把握しましょう。 |
| **環境内のヒント** | チョークの跡、勤務割表、地図、隠されたコードが記されたポスターなど。 | プロパガンダ看板などに書かれた4桁の数字を見つけたら、スクリーンショットを撮るかメモしておきましょう。 |
| **ステルスのタイミング** | サーチライトの照射や監視カメラの首振りの間にある安全な時間枠。 | 動く前に2サイクル分しっかりと観察し、巡回ルートのタイミングを把握してください。 |

## フェーズ 1: 拘留兵舎

任務は高セキュリティの独房の中から始まります。フェーズ1の目的は、基本的なピッキングツールを入手し、独房の扉を突破して、警報を鳴らさずに通路の監視カメラを無力化することです。

```
[独房 B-4] ---> [ロッカー通路] ---> [警備分所] ---> [中庭ゲート]
```

### 独房のステップバイステップ攻略

1. **二段ベッドを調べる**: 下段ベッドの擦り切れたマットレスを持ち上げると、**曲がったワイヤーフレーム**が見つかります。
2. **洗面台を調べる**: 洗面ボウルの下にある排水パイプをタップします。緩んでいるボルトを使ってパイプクランプを緩め、**金属ワッシャー**を入手します。
3. **アイテムを合成する**: インベントリを開き、**曲がったワイヤーフレーム**と**金属ワッシャー**を合成して**即席のロックピック**を作成します。
4. **独房の鍵をピッキングする**: 格子戸の鍵穴を調べます。2時の位置と8時の位置で手応え（クリック音）があるまでピックを回転させます。

### 拘留セクター アイテムリファレンス

| 部屋の場所 | 必要なツール | 入手アイテム | 用途 |
| :--- | :--- | :--- | :--- |
| **独房 B-4** | なし | 曲がったワイヤーフレーム | ロックピックの基礎作成素材 |
| **独房 B-4 洗面台** | 手動操作 | 金属ワッシャー | テンションレンチの部品 |
| **警備デスク** | 即席のロックピック | レベル1 セキュリティキーカード | 警備分所のドアを開ける |
| **ロッカー #104** | 3桁の暗証番号 (`482`) | ドライバー | 通路の通気口カバーを取り外す |

コミュニティフォーラムで報告されているプレイヤーの体験談によると、フェーズ1でよくある失敗は、通気口を這って通った後にカバーを戻し忘れることです。これにより巡回中の警備兵に気づかれ、警報が鳴る原因になります。

## フェーズ 2: 司令センターと無線室

独房エリアを抜け出したら、次は戦術司令室に潜入し、基地の外周フェンスを無効化して救出地点の座標を傍受する必要があります。このステージでは、無線暗号パズルを解読するために、この **Army Escape 攻略** の手順を正確になぞる必要があります。

### 司令センターのパズルコード

中央ターミナルを操作するには、壁の勤務割表から割り出す4桁の認証コードが必要です。司令官の作戦コールサインと、ブリーフィングボードに表示されているシフト日を照合してください。

| ターミナル / 金庫 | パズルの種類 | 解答 / コード | 報酬 / 結果 |
| :--- | :--- | :--- | :--- |
| **将校の金庫** | シフト暗号 | `7193` | タクティカルナイフ & レベル2 キーカード |
| **無線受信機** | 周波数調整 | `104.5 MHz` | 傍受した救出グリッド（セクター7） |
| **ブレーカーパネル** | 配線の色合わせ | 赤 $\rightarrow$ 3、青 $\rightarrow$ 1、黄 $\rightarrow$ 4 | 内部の赤外線レーザーを解除 |
| **メインサーバー** | バイナリスイッチパズル | `1-0-1-1-0` | 中庭水門の制御装置をアンロック |

配電盤の配線パズルを解く際は、必ず左側にある主電源レバーを最初に下げてください。感電してゲームオーバーになってしまいます。さらに多彩なパズル攻略法やゲーム全体の進行手順を学びたい方は、[IGNの詳細な攻略ガイド](https://www.ign.com/wikis) もチェックして、戦術アドベンチャーの腕を磨きましょう。

## フェーズ 3: 兵器庫と車両基地

司令セクターをクリアしたら、開けた車両基地を横断し、確実な脱出用車両か外周フェンスを切断するための工具を手に入れる必要があります。兵器庫には、外門のロックボックスを破壊するために必要な大型ツールが保管されています。

```
[無線室 出口]
       │
       ▼
 [車両基地の広場] ──(サーチライト回避)──► [兵器庫バンカー]
       │                                              │
       ▼                                              ▼
 [ジープのバッテリー探索] ◄────────────────── [大型ボルトクリッパー]
```

### 車両基地 目標達成表

| ステップ | 目標 | 主な危険要素 | 推奨アクション |
| :--- | :--- | :--- | :--- |
| **1** | 中庭を横断する | 回転式サーチライトタワー | 輸送コンテナの間を4秒間隔でダッシュ移動する。 |
| **2** | 兵器庫バンカーに侵入する | 頑丈なスチール製南京錠 | メンテナンスラックBにある**大型ボルトクリッパー**を使用する。 |
| **3** | 車両パーツを回収する | 軍用犬の巡回 | 食堂で見つけた肉の配給食を投げ、軍用犬の気をそらす。 |
| **4** | 輸送トラックに給油する | 燃料パイプの漏れ | ディーゼルを給油する前に、絶縁テープでホースの裂け目を補修する。 |

### 兵器庫の武器ラックとロッカー

兵器庫内に入ったら、壁際の武器ラックを探索します。主兵装は生体認証ケースにロックされていますが、ユーティリティ装備は自由に回収可能です：
* **スモークグレネード**: 防爆ドア近くの木箱#3に入っています。中庭で見つかった場合に使用してください。
* **C4爆薬＆起爆装置**: ロッカー#12に保管（レベル2 キーカードが必要）。ゲートが詰まって開かない場合の予備脱出ルート作成に必須です。
* **レンチ（12mm）**: 車両整備ベイのカートの上にあります。軍用トラックのバッテリーを回収する際に必要です。

## フェーズ 4: 外周突破と最終脱出

この **Army Escape 攻略** の最終章では、脱出ゾーンへのラストスパートを解説します。外周ゲートの主制御を作動させると基地全体に警戒態勢が敷かれるため、スピードと正確な行動が命運を分けます。

### 最終脱出ルートの選択肢

コミュニティの報告によると、これまでのフェーズで入手したアイテムに応じて、主に2つの脱出ルートが選択可能です：

| ルート選択 | 必要なインベントリアイテム | 難易度 | メリット / デメリット |
| :--- | :--- | :--- | :--- |
| **ルートA: 軍用トラック突破** | トラックバッテリー、軽油缶、イグニッションキー | 中 | 素早い脱出が可能でスナイパータワーを無視できるが、大きなエンジン音でアラームが鳴る。 |
| **ルートB: 排水路潜入** | バール、懐中電灯、大型ボルトクリッパー | 高 | 完全なステルス脱出が可能で車両系アラートを回避できるが、複雑な水門バルブパズルがある。 |

### 最終ゲートパズルのクリア手順

ルートAを実行する場合：
1. フル充電された**トラックバッテリー**をエンジンルームに取り付けます。
2. **12mmレンチ**を使ってケーブルを固定します。
3. **軽油缶**の中身を燃料タンクに注ぎます。
4. 将校の金庫から回収した**イグニッションキー**を差し込みます。
5. 外側の木製バリケードをトラックで突き破れば、ミッションクリアとなります。

## プロのアドバイスと高度なサバイバル戦術

ノーミスでのクリアや最高スコア評価を獲得するために、プレイ中は以下の戦術的ヒントを意識しましょう：

* **アイテムは計画的に温存する**: 最終中庭に入るまで、空の缶や布切れは絶対に捨てないでください。序盤のアイテムの多くは、敵の気を引くデコイとして再利用できます。
* **マップの配置を記憶する**: ロッカーの場所を暗記しておきましょう。警報が鳴っても、ロッカーの中やデスクの下に隠れれば、15秒で警備兵の警戒メーターがリセットされます。
* **画面の明るさ調整**: ゲーム内のガンマ値を少し上げると、壁の薄い鉛筆メモや、暗い幅木の隅に落ちている隠し鍵を見つけやすくなります。
* **こまめなセーブ管理**: ステルス区間に突入する前や新しい通路に入る直前には手動セーブを作成し、失敗時の進行ロスを防ぎましょう。

## よくある質問（FAQ）

### Army Escapeで兵器庫の鍵はどこにありますか？
兵器庫の鍵は、司令センター内にある将校の金庫の中にあります。金庫を開けるには、司令官の勤務割表から導き出される4桁の日付コード（`7193`）を使用したシフト暗号を解く必要があります。

### 中庭のサーチライトに見つかった場合はどうすればいいですか？
サーチライトに捉えられたら、即座にスモークグレネードを使用するか、最も近い貨物コンテナの陰に飛び込んでください。視線を切り、イエロー警戒状態が通常に戻るまで10秒間待機してから、本 **Army Escape 攻略** に記載されたルートを再開してください。

### 無線室の通路にあるレーザー格子はどうやって解除しますか？
隣接する壁にある配電盤パネルを開け、主電源レバーを引き下げてから、色付きのワイヤーを対応する番号の端子（赤 $\rightarrow$ 3、青 $\rightarrow$ 1、黄 $\rightarrow$ 4）に接続し直すと、安全に赤外線ビームを無効化できます。

### 警報を一度も鳴らさずにArmy Escapeをクリアすることは可能ですか？
はい、可能です。軍用トラックを使わずに排水路を通るルートBを選び、ドライバーとボルトクリッパーを活用して進むことで、アラームゼロの完全ステルス（ゴースト）脱出評価を達成できます。
