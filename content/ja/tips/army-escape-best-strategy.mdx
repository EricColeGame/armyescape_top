## キャンペーンの移動メカニズムを理解する

強力な敵から逃げ切るには、まずワールドマップ上での部隊移動速度を左右する基本要素を理解しなければなりません。運んでいる穀物の量から騎兵の比率に至るまで、あらゆる判断が追跡者を振り切れるかどうかに直結します。

追撃してくる敵部隊は複数の領主が合流した大軍であることが多く、重い兵站ペナルティを抱えています。こうした鈍重な編制に対しては、その遅い基本移動速度を突くことで簡単に立ち回ることができます。

| 移動要因 | 部隊速度への影響 | 最適化戦略 |
| :--- | :--- | :--- |
| **騎兵比率** | 基本速度 +0.5 〜 +2.0 上昇 | 予備の馬を用意して全歩兵を騎乗移動させる |
| **所持品過載（重量オーバー）** | 最大 -3.0 の速度ペナルティ | 低ティアの戦利品や余剰な重い交易品を破棄する |
| **負傷兵** | -0.2 〜 -1.5 の速度ペナルティ | 医術（Medicine）パークに投資し、治療を優先する |
| **家畜の連行ペナルティ** | 最大 -2.5 の速度ペナルティ | 家畜の数を部隊メンバー1人あたり1〜2頭以下に抑える |
| **地形補正** | -10% 〜 -40% の速度低下 | 斥候なしでの深い森林、豪雪地帯、砂丘を避ける |

高い士気を維持することで、移動速度に固定の追加ボーナスが得られます。敵の前衛が迫っている場合、鉄鉱石や木材などの重い交易品を投げ捨てることで、川の浅瀬を渡ったり味方の城壁へ逃げ込んだりするために必要な速度のブーストを瞬時に得ることができます。

## 味方軍勢および敵対拠点からの離脱

最も危険な戦術的シナリオの1つは、味方指揮官の軍勢に所属している際に、AIが破滅確定の拠点や脱出不可能な包囲網へ直接進軍してしまうケースです。安全に部隊を切り離す方法を理解することは、**部隊脱出の最強戦略**における極めて重要な基盤です。

プレイヤーの経験やコミュニティの報告によると、圧倒的な敵軍が到着する直前に味方連合軍が街に入ってしまい、自部隊が身動き取れなくなる事態が頻繁に発生します。全滅を避けてこの手詰まりから脱出するには、拠点インターフェースを使用して即座に部隊を離脱させます：

1. 休息中または閉じ込められている状態で、拠点または都市のハブメニューを直接クリックします。
2. **「軍勢を離れる（Leave Army）」**または**「離脱（Disengage）」**オプションを選択し、連合軍から自部隊を切り離します。
3. 移動を開始する前に、ワールドマップ上で敵の視界（索敵範囲）を即座に確認します。
4. 味方の領土または防御設備のある城に向かって移動ルートを設定します。
5. 目前の危機が去った後、必要に応じて再び連合軍に合流します。

| 離脱方法 | 結束度 / 関係性への影響 | 危険度 | 推奨される使用状況 |
| :--- | :--- | :--- | :--- |
| **通常離脱（都市メニュー）** | 軽微な影響力低下（-1 〜 -5） | 低 | 味方軍勢が危険な戦闘エリアや絶望的な包囲戦に進入した時 |
| **マップからの緊急離脱** | 中程度の影響力低下（-10 〜 -20） | 中 | 連合軍の指揮官が敵の大軍（デスボール）に突撃している時 |
| **殿（しんがり）犠牲撤退** | 部隊の大きな損失（兵力の10-20%） | 高 | 平原で複数の敵軍に完全包囲された時 |
| **和平協定の利用** | 多額のデナル支出 / 王国投票 | 戦闘リスクゼロ | 勢力の完全滅亡を防ぐための最終手段 |

## 戦術的撤退と殿（しんがり）の犠牲

勝ち目のない圧倒的な戦力差で戦闘に突入してしまった場合、組織的な戦術撤退の手順を知っていれば、壊滅的な全滅（ワイプ）を防ぐことができます。戦闘シミュレーション（委任）によって最高ティアのユニットを失うのではなく、手動戦闘での撤退ルールを活用する必要があります。

戦術戦闘では、部隊をマップ端まで後退させることでインスタンスから脱出させることができます。ただし、戦闘システムによって完全交戦状態にロックされた場合は、殿（しんがり）を犠牲にする戦術を実行することで、主要な指揮官や騎兵を逃がすことが可能です。

| 撤退フェーズ | 戦術アクション | 最優先目標 |
| :--- | :--- | :--- |
| **フェーズ1：前衛の牽制** | 高速な弓騎兵や軽騎兵に敵の側面への嫌がらせを命じる | 敵戦列の前進を遅らせる |
| **フェーズ2：防御陣形** | 重歩兵で強固なシールドウォール（盾壁）を形成する | 弓兵や高ティアのコンパニオンを保護する |
| **フェーズ3：撤退命令** | 戦闘コマンドを使用してマップ境界からの離脱を開始する | 大規模な損害が出る前にベテランユニットを保護する |
| **フェーズ4：ワールドマップでの逃走** | 余分な荷物を捨ててマップ上の移動速度を最大化する | 戦闘直後の猶予時間の間に距離を稼ぐ |

完全包囲に直面した際は、低ティアの新兵を殿として残して足止めさせることで、高ティアのコンパニオンや騎兵を脱出させることができます。キャンペーンバランスや戦術撤退メカニクスに関する最新のアップデートについては、[Mount & Blade 公式コミュニティハブ](https://store.steampowered.com/app/261550/Mount__Blade_II_Bannerlord/)の公式バトルガイドラインをご確認ください。

## 戦略的な地形選択とチョークポイント回避

**部隊脱出の最強戦略**を実行する上で、地形や環境の活用は欠かせません。地形は追撃軍がどれだけ早く距離を詰められるかを左右するため、小規模で機敏な部隊は鈍重な大軍に対して圧倒的なアドバンテージを得ることができます。

川の橋、山の峠道、密林を利用することで、敵の視界を遮り、敵軍に大幅な遠回りを強いることが可能です。

```
[敵の大軍（速度: 3.8）] 
           │
           ▼
[山のチョークポイント / 森林] ──► (大軍に30%の地形ペナルティを付与)
           │
           ▼
[プレイヤーの軽快部隊（速度: 5.4）] ──► [安全圏: 味方の砦 / 同盟領土]
```

| 地形タイプ | 速度への影響（大軍） | 速度への影響（小規模部隊） | 最適な回避戦術 |
| :--- | :--- | :--- | :--- |
| **平原・草原** | 0%（最速移動） | 0% | 純粋な騎兵速度を活かして距離を開く |
| **森林・樹林帯** | -30% 〜 -40% 低下 | -15%（「森林の民」パーク適用時） | 視界を切り、進路を変更する |
| **雪原・ツンドラ** | -25% 基本速度低下 | -10%（「スノーランナー」パーク適用時） | 未適応の南方軍を誘い込み、移動力を奪う |
| **川の渡河地点** | 大幅なボトルネックによる遅延 | 一列での迅速な通過 | 橋を渡り、チョークポイントを維持して追撃を遅らせる |
| **山の峠道** | 単一ルートへの進路制限 | 狭い隙間を通る高い機動性 | 敵軍に山脈全体の迂回を強いる |

## 必須の斥候パークとキャラクタービルド

部隊の生存率は、スカウト（Scouting）と戦術（Tactics）スキルに大きく依存します。特定のパークを習得することで、パッシブな移動速度ボーナス、足跡探知、夜間移動や悪路でのペナルティ軽減などの恩恵を受けられます。

これらの特殊能力を組み合わせることが確実な**部隊脱出の最強戦略**の基盤となり、あらゆる環境条件下でも自部隊の機動力を高く維持できます。

| スキルツリー | 主要パーク名 | システム上の利点 | 脱出時の有用性 |
| :--- | :--- | :--- | :--- |
| **スカウト（Scouting）** | *Foragers（採集者）* | 平原での移動速度 +5% | 重い大軍から逃げ切るために必須 |
| **スカウト（Scouting）** | *Night Runner（ナイトランナー）* | 夜間移動ペナルティを無効化 | 敵が鈍足化している夜間に脱出が可能 |
| **スカウト（Scouting）** | *Forest Kin（森林の民）* | 歩兵の森林移動速度低下を無効化 | 密林を抜ける迅速な逃走を実現 |
| **戦術（Tactics）** | *Loose Formations（散開陣形）* | 撤退シミュレーション時の損害を軽減 | 戦闘からの逃走時の損失を最小化 |
| **騎乗（Riding）** | *Nomadic Traditions（遊牧の伝統）* | 騎乗兵の部隊速度を +10% 向上 | マップ全体の移動速度を最大化 |
| **運動能力（Athletics）** | *Formations（隊形移動）* | 非騎乗歩兵の徒歩移動速度を向上 | 足の遅い新兵が部隊全体の速度を下げるのを防止 |

部隊のスカウト担当へのスキルポイント投資は、キャンペーン序盤から中盤にかけて最優先で行うべきです。高い狡知（Cunning）と移動関連パークを持つ専任スカウトがいれば、部隊の移動速度を5.5以上に維持でき、一般的な軍事連合から捕捉されるリスクをほぼゼロにできます。

## よくある質問（FAQ）

### 大軍に追い詰められた際、最も効果的な部隊脱出の最強戦略は何ですか？
最も確実な方法は、重い所持品を捨てて重量オーバーを解消し、森林や山岳などの移動が困難な地形へ逃げ込み、軽騎兵で敵の視界を遮ることです。戦闘が始まってしまった場合は、防御的なシールドウォールを配置し、マップ端で即座に撤退コマンドを実行することで兵力の損失を最小限に抑えられます。

### 味方軍勢の一部として都市内に閉じ込められた場合、どうやって脱出すればよいですか？
拠点インターフェースを開き、「軍勢を離れる（Leave Army）」または「離脱」オプションを選択することで、敵の包囲部隊が包囲網を完成させる前に、自部隊単独で城門から外へ脱出することができます。

### 戦利品を捨てるとキャンペーンマップの移動速度は上がりますか？
はい。部隊の積載許容量を超える重量を持つと深刻な速度ペナルティが発生します。余分な交易品、鹵獲した武器、家畜を捨てることで、基本移動速度を即座に取り戻すことができます。

### 高い戦術（Tactics）スキルは戦闘を行わずに脱出するのに役立ちますか？
はい。戦術スキルが高いと、「敵を足止めするために兵を残す（殿を置く）」を選択した際の犠牲者の割合が減少します。これにより、低ティア兵の最小限の犠牲で主力部隊を安全に離脱させることが可能になります。
